# 🚀 Cara Mengakses Template Javanese Elegant

## 📍 URL Akses

### 1. Homepage
```
http://localhost:3000
```
- Landing page dengan hero section
- Klik "Lihat Template" atau "Mulai Sekarang"

### 2. Gallery Template
```
http://localhost:3000/templates
```
- Lihat semua template tersedia
- Filter by kategori
- Klik "Gunakan Template" pada **Javanese Elegant**

### 3. Editor Template
```
http://localhost:3000/editor/javanese-elegant
```
- **Direct access ke editor!**
- Edit informasi mempelai
- Edit detail acara
- Preview real-time
- Lihat media built-in

### 4. Preview Undangan Lengkap
```
http://localhost:3000/invitation/preview
```
- **Direct access ke preview undangan!**
- Lihat full experience:
  - Button "Buka Undangan"
  - Video intro animasi
  - Smooth transition
  - Bismillah & cover
  - Ayat Quran
  - Info mempelai dengan foto
  - Kisah pertemuan
  - Detail acara (Akad + Resepsi)
  - Galeri foto
  - Form RSVP
  - Background music dengan kontrol

## 🎨 Fitur Utama Template

1. **Opening Elegan**
   - Button "Buka Undangan"
   - Ornamen tradisional
   - Smooth fade-in

2. **Video Intro Cinematik**
   - Animasi gunungan 3D
   - Durasi 10-15 detik
   - Auto-play setelah dibuka

3. **Cover Javanese**
   - Bismillah di atas
   - Nama mempelai elegant
   - Hashtag
   - Ornamen emas berputar

4. **Ayat Quran**
   - QS. Ar-Rum: 21
   - Teks Arab + Latin
   - Design card elegan

5. **Mempelai dengan Foto**
   - Frame foto emas traditional
   - Ornamen bunga
   - Info lengkap orang tua

6. **Kisah Pertemuan**
   - Icon love animated
   - Text italic romantis

7. **Detail Acara**
   - 2 Cards: Akad + Resepsi
   - Icon religious
   - Button Google Maps
   - Hover effect premium

8. **Galeri Foto**
   - Grid 4 foto
   - Hover overlay
   - Ornamen tradisional

9. **RSVP Form**
   - Form konfirmasi kehadiran
   - Input nama, jumlah tamu
   - Textarea ucapan & doa

10. **Background Music**
    - Gamelan tradisional
    - Auto-loop
    - Kontrol on/off
    - Floating button
